About BTX Node

A full node keeps its own complete, verified copy of the BTX blockchain and checks every block against the rules — no trust in anyone else's server. Nodes relay blocks and transactions between peers and help new nodes join.

BTX Node runs one for you: it fast-started from a checksum-verified snapshot, keeps the node healthy in your menu bar, and shows you what it's doing. No wallet, no mining, no account — just you, helping the network stay decentralized.

The full chain measured 124 GiB on 2026-09-04 and now grows about 8 MB a day, so the space it needs is mostly the history it already has. BTX has no node rewards today — this one is for the network. Settings can remove the chain data anytime.

What we're planning

  • Ask your node — shipped in v0.2: cited answers about the chain, straight from your own node. Tap the ? in the header.
  • Node supporter identity — a way for your node to say "I was here", with stats you can share.
  • Compute contribution — opt in to donate spare compute to useful network work, using the node's built-in service RPC.
  • Following the chain past 185,000 on any machine — today that needs an Apple Silicon Mac or one of the newest graphics cards. A mode that works everywhere is being built by the BTX team; when it is safe to leave running unattended, it ships here.
  • Making it worth your while — if the network adds node incentives, this app is where they land first.

These are plans, not promises — order and shape can change. Already shipped: the wallet, and Windows and Linux builds.
